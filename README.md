# Escola para Todos

##### Educação, inclusão e oportunidades.

##### Página web de conscientização sobre a importância da escola, da educação inclusiva e da acessibilidade, desenvolvida como atividade acadêmica de Acessibilidade Web e HTML Semântico.

##### 

# Demonstração

##### Abra o arquivo `index.html` em qualquer navegador moderno (Chrome, Firefox, Edge ou Safari). Não há dependências, frameworks ou JavaScript — apenas HTML5 e CSS3 puros.

Repositório no GitHub: https://github.com/SEU-USUARIO/escola-para-todos

# Recursos de acessibilidade implementados

* ##### `lang="pt-BR"` no elemento `<html>`;
* ##### HTML semântico: `header`, `nav`, `main`, `section`, `article`, `aside`, `footer`, `figure`, `figcaption`;
* ##### Hierarquia correta de títulos (um único `h1`, seguido de `h2` e `h3`);
* ##### Link "Pular para o conteúdo principal" (skip link);
* ##### Imagens com `alt` descritivo;
* ##### Formulário com `label` associado a cada campo, `fieldset` e `legend`;
* ##### Destaque visual de foco com `:focus-visible` (navegação por teclado);
* ##### Paleta de cores com contraste verificado segundo a WCAG AA;
* ##### Layout responsivo (desktop e celular);
* ##### Links e botões com textos descritivos.
